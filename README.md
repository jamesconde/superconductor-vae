# Superconductor VAE

This repository has been made private while intellectual property and commercialization options are being explored.

## About the Project

FullMaterialsVAE is a multi-task generative model (114.8M parameters) for superconductor discovery. It jointly predicts critical temperature (Tc) and reconstructs chemical formulas in a shared latent space, enabling targeted generation of novel superconducting candidates.
